# Connor Neary Software Development Portfolio

A static portfolio for a third-year TUS Athlone student seeking placement from January 2027. It includes the MMA tracker, Java gym membership API, country weather dashboard, personal background, academic results, future ideas and contact details.

## Open the website

Extract the folder and open index.html. Keep the files and folders together. There is no installation or build step.

## Files

|   Path    |       Purpose         |

| index.html | Page content, screenshots, navigation and downloads. |
| w3.css | The original W3.CSS 4.15 stylesheet, included unchanged. |
| style.css | Short custom styles for fonts, colours, heading sizes and images. |
| assets/ | Six project screenshots. |
| downloads/ | The three project source ZIPs and Connor_Neary_CV.pdf. |
| .nojekyll | Empty marker for serving plain static files on GitHub Pages. |

The screenshot expansions use HTML details and summary. No JavaScript is needed. The projects are first in the HTML, so they appear before About and education on small screens.

## Project downloads

- MMA Fight Results Tracker: the latest uploaded Python coursework, with PyQt5, SQLite and SQLAlchemy. Its source is unchanged and the screenshots use fictional demonstration records.
- Gym Membership REST API: original Java/Spring Boot coursework, with Maven setup notes.
- Country Weather Dashboard: original HTML, CSS and JavaScript coursework, with setup notes.

The project ZIPs are separate applications. The portfolio displays their screenshots and descriptions.
