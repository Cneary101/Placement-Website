# Connor Neary — Software Development Portfolio
A personal portfolio for a third-year TUS Athlone student seeking software placement from January 2027. The page contains an introduction, education results, selected projects, future ideas and contact details.

## View locally
Extract the complete ZIP, then open index.html. Keep the assets and downloads folders beside it. The portfolio uses plain HTML and CSS and does not need an installation or build step.

## Files
|     Path     |     Purpose     |
| index.html | Portfolio content, screenshots, links and expandable details. |
| style.css | Colours, layout and mobile rules. |
| assets/ | Five screenshots used by the page. |
| downloads/ | Source ZIPs for the three featured projects, each with setup notes, plus Connor_Neary_CV.pdf. |
| DEPLOYMENT.md | GitHub Pages upload steps. |

## Project downloads
- Gym Membership REST API: original Java/Spring Boot source, Maven configuration and setup notes. Generated build output and IDE-specific files are excluded.
- Country Weather Dashboard: original HTML, CSS and JavaScript with setup notes. It uses external APIs and CDN resources when run separately.
- Internship Application Tracker: Python/PyQt5/SQLite source, tests, screenshots, setup instructions and code explanation. It runs as a separate desktop app.

## GitHub
Upload the CONTENTS of this folder to your repository root. index.html must appear directly at the root alongside style.css, assets and downloads. Use the included DEPLOYMENT.md for the Pages settings.

## CV download
The introduction includes a Download my CV button pointing to downloads/Connor_Neary_CV.pdf. This is the existing two-page internship CV, included unchanged. To replace it later, save the new PDF with the same filename and upload it to the same folder.
